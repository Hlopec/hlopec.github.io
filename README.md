# Бюджет (web)

Вебзастосунок для ведення особистого бюджету з серверною частиною на Node.js. Дані зберігаються у файлі `data/db.json`, тож вони доступні з різних пристроїв, якщо запустити сервер.

## Старт локально

```bash
cd hlopec.github.io
npm start
# сервер підніметься на http://localhost:3000 і одразу віддаватиме фронтенд та API
```

> За потреби можна просто виконати `node server.js`, але npm-скрипт коротший.

Сервер самостійно створює файл бази даних (формат JSON) і надає просте REST API:

- `GET /api/state` — всі транзакції та кредити;
- `POST /api/transactions`, `DELETE /api/transactions`, `DELETE /api/transactions/:id`;
- `POST /api/credits`, `DELETE /api/credits`, `DELETE /api/credits/:id`.

## Можливості

- додавання доходів та витрат із описом, категорією, датою та сумою;
- автоматичні підрахунки балансу, сум доходів/витрат, а також відображення балансу в гривні та доларах за поточним курсом НБУ;
- фільтрація за категорією та діапазоном дат;
- розбивка сум за категоріями;
- ведення кредитів за різними категоріями (окремий список, автоматичний розрахунок загальної суми);
- видалення окремих записів або очищення всієї історії (включно з кредитами) з фіксацією в базі даних.
