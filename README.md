# Бюджет (web)

Проста клієнтська вебпрограма для ведення особистого бюджету. Дані зберігаються у `localStorage`, тому їх не потрібно відправляти на сервер, а застосунок можна розгорнути як статичний сайт на будь-якому хостингу або локально.

## Старт локально

```bash
cd budget
python3 -m http.server 8000
# або, якщо у вашому середовищі python3 називається просто python:
# python -m http.server 8000
# далі відкрийте http://localhost:8000 у браузері
```

Будь-який інший статичний сервер (Node `serve`, Nginx, GitHub Pages тощо) теж підійде.

## Можливості

- додавання доходів та витрат із описом, категорією, датою та сумою;
- автоматичні підрахунки балансу, сум доходів/витрат, а також відображення балансу в гривні та доларах за поточним курсом НБУ;
- фільтрація за категорією та діапазоном дат;
- розбивка сум за категоріями;
- ведення кредитів за різними категоріями (окремий список, автоматичний розрахунок загальної суми);
- видалення окремих записів або очищення всієї історії (включно з кредитами).
